# Notice

This repository contains original benchmark code, metadata, derived outputs,
tables, and figures produced for the associated manuscript. Raw public data
files are not redistributed.

Original public data sources:

- Behavioral Risk Factor Surveillance System annual public-use files, 2011-2023.
- National Health and Nutrition Examination Survey public-use files, 2011-2018.
- UCI Machine Learning Repository diabetes 130-US hospitals readmission dataset.

Users who rerun or extend the benchmark should download source datasets from
the original providers and comply with each provider's terms of use and
citation requirements.
